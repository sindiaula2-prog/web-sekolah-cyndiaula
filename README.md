# Web Sekolah - SMK Negeri 1 Cijati

Website resmi SMK Negeri 1 Cijati, dibuat sebagai project UKK (Uji Kompetensi Keahlian).

## Tentang

Website ini berisi informasi seputar sekolah seperti profil, jurusan, fasilitas, berita, agenda, ekstrakurikuler, dan galeri kegiatan.

## Teknologi yang digunakan

- Laravel (PHP Framework)
- Blade Template
- MySQL / SQLite
- CSS & JavaScript

## Fitur

- Halaman beranda sekolah
- Profil sekolah (sejarah, visi misi, fasilitas)
- Informasi jurusan
- Berita & agenda sekolah
- Galeri kegiatan & ekstrakurikuler
- Halaman kontak

## Cara Instalasi

1. Clone repository ini
2. Jalankan `composer install`
3. Copy `.env.example` menjadi `.env` dan sesuaikan konfigurasi database
4. Jalankan `php artisan key:generate`
5. Jalankan `php artisan migrate`
6. Jalankan `php artisan serve`
